Repeater plan

The current repeater plan is saved on this PC. Save a plan file to keep another copy or share it with another Command user. Opening a file replaces the current plan; coverage and links can then be recalculated.

Plans are sent as multiple encrypted packets to a verified Secure Coms contact. Both apps need this feature and must stay connected. Large plans take time and airtime.

Known repeaters need advertised locations. Their antenna height starts at 1 m; adjust it if known. Bulk coverage may take time and appears as each layer completes. The coverage radius setting applies separately to each node. Other planned nodes stay on the map but are excluded until selected.

Message routing

Command clears a recipient's saved path immediately before sending direct, room and secure messages to request flooding. Channel messages use flood routing. The radio can learn paths again, and Command warns if a send is reported as direct or its route is unknown. Flooding increases mesh traffic. Off-grid companion repeat

Optionally forward packets while continuing to use this board as a companion. Intended for small off-grid networks without repeater infrastructure; it is not a managed repeater.

The radio only permits this mode on its allowed frequencies. Changing frequency to use an off-grid network disconnects you from your usual mesh until matching settings are restored. This control never changes the frequency.

Connect a radio, then check whether its current frequency permits companion repeat. The firmware may not report whether repeat is currently enabled.

Radio

Radios need matching settings to hear each other. UK Narrow: 869.618 MHz, 62.5 kHz, SF8, CR 4/8. Saving radio settings disables companion repeat; re-enable it afterwards if needed.

The V4 has an external amplifier: this setting is not necessarily the final radiated power.

Runs while Command is connected. Favourites, Secure Coms contacts, monitored nodes and saved rooms are protected. The oldest last advert or received direct message is used; contacts with no valid advert time are skipped. Radio-side overwrite settings operate independently.

Encrypted backup

Save PC settings, messages, Secure Coms secrets, situation maps and saved passwords. Include the connected radio to back up its identity, contacts, channels and supported settings. Keep the password safe; it cannot be recovered. Offline map files are limited to 256 MB total. Wi-Fi credentials, radio message queues, some firmware-specific settings and other devices are not included.

One backup includes Secure Coms. Import also accepts older Secure Coms backup files. For a new PC and radio, import the backup and then restore the connected radio using the same file. Radio restore overwrites its identity and matching settings. Recovery backups are created before changes. Recheck Secure Coms fingerprints; old backups cannot contain newer replay records.
